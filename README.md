# svg-render

让游戏直接画 SVG，画得和 Chrome 一样；画面很丰富、一屏很多 SVG 也流畅。先做 Godot（mac 桌面），以后做 Cocos 3.8.x（H5）。用 C++ 写。

设计文档、美术、参考文件都在这个仓库里，不用读仓库外面的东西。

## 现在做到哪

**阶段 0：参照和对照**，还没开工。照 [`docs/阶段0-需求.md`](docs/阶段0-需求.md) 做，在 `stage-0` 分支上。

## 目录

```
docs/        设计文档、试验脚本、测试图需求（只读）
素材/
  源文件/    美术原件（只读）：现有游戏、待接入、复杂测试图
  字体/      Noto Sans CJK SC 两个字重（只读，OFL 许可）
  试验图/    设计时用的一张小试验图
参考/        现有卡牌游戏的几份文件，只当参考（只读）
```

代码和工具照 `docs/阶段0-需求.md` 第 2 节的目录建。`out/` 是生成物，不进版本管理；要人看的汇总放 `报告/`。下载的 Chrome、Skia 源码、测试集放在 `~/Library/Caches/svg-render/`，也不进仓库。
