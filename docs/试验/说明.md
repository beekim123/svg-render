# 试验说明

> Fable 5.2 为了核实设计里的几件事写的小脚本，2026-11-10 至 11 日在本机（M3，Chrome 157.0.8103.39）跑的。
> **不是正式代码。** 思路可以给阶段 0 参考。只读现有游戏和测试图，不改它们；只关自己开的那个 Chrome。

## 怎么跑

需要 Node 22 以上和本机的 Chrome（用环境变量 `CHROME` 可以换成别的）。比图需要 Python 3 加 numpy 和 Pillow。

```bash
# 在仓库根目录跑
node docs/试验/试验1-冻结取值截图.mjs cpu
```

输出都在 `输出/`。

## 每个试验核实了什么

| 文件 | 核实什么 | 结果 |
|---|---|---|
| `cdp.mjs` | 公用：开一个无头 Chrome，用调试协议控制；能问出现在是 CPU 光栅还是 GPU 光栅 | — |
| `试验图.svg` | 一张小图，把测试图需求里的几种动画各放一个（CSS 的变换、路径形变、颜色、虚线偏移；SMIL 的路径形变、模糊半径、渐变平移、沿路径运动、set；一个要触发的一次性动作） | — |
| `试验1-冻结取值截图.mjs` | CSS 动画和 SMIL 能不能一起停在任意毫秒；一次性动作能不能在暂停的时间线上触发；动画值能不能读出来；同一时刻截图是否每次一样 | 都能。CPU 和 GPU 两种模式下，同进程来回跳、换进程，7 个时刻的截图全部逐字节相同；读出来的值也完全相同。SMIL 形变后的路径能从计算样式的 `d` 里读到；模糊半径、渐变变换从 `animVal` 读；沿路径运动从 `getCTM()` 读 |

| `试验3-取Chrome指令.mjs` | 能不能拿到 Chrome 发给 Skia 的绘制指令 | 调试协议的 `LayerTree.snapshotCommandLog` 能拿到（画路径、画椭圆、画矩形、存层等，带画笔的标志位）；渐变和滤镜的内部参数是空的。`printToSkPicture` 在无头模式下没写出文件。顺带看到：动画暂停时，Chrome 把会动的元素拆成了单独的合成层 |
| `试验4-活图对冻结图.mjs` | Chrome 自己"动画停住直接截"和"值写死后重画"差多少 | 现有游戏 7 个动作：1 倍相似度 0.964–0.998，2 倍 0.975–0.995。活图明显更软（合成层被变换后重采样）。这个数用来定"运动中允许发软多少" |

## 从试验里学到、已经写进设计的几件事

1. 参照要用 CPU 光栅，而且用"冻结图"。
2. Chrome 的 CPU 光栅和 GPU 光栅在图的最下面一行会差出一条 1 像素高的线，所以"最大差异块"要先去掉 1 像素宽的细线。
3. 播完的 CSS 动画会从 `getAnimations()` 里消失，工具要自己把动画对象记住。
4. `animVal` 的变换列表是只读的，不能调 `consolidate()`，要自己把各项矩阵乘起来。
5. Chrome 画圆用"画椭圆"，画矩形用"画矩形"，渐变的画笔带抖动标志。素材文件里要保留图元的原始种类。
