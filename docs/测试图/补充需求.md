## 2 新文件

### 2.1 三个"会被染色"的图标（128×128）

游戏里同一个图标常常要按阵营或稀有度换颜色。做法是：图标里会变色的部分用 `currentColor` 画，游戏改根元素的 `color` 就换了颜色。上次的 40 个文件里一处 `currentColor` 都没有，所以要补。

三个图标对应三种情况，**不要混用**：

| 文件 | 画什么（参考，可以换） | 规则 |
|---|---|---|
| `icons/icon_tint_flat.svg` | 阵营旗帜或纹章，剪影风格 | **只用 `currentColor`**：所有形状的 `fill` 和 `stroke` 都是 `currentColor`，不准出现别的颜色，也不要渐变和滤镜。深浅可以用 `opacity` 或 `fill-opacity` 做 |
| `icons/icon_tint_shaded.svg` | 药水瓶 | 瓶身用 `currentColor` 的纯色；上面叠**固定颜色**的高光（白色半透明）和阴影（黑色半透明）；最后整个图标套一层做旧颗粒滤镜（`feTurbulence` 加 `feComposite` 之类） |
| `icons/icon_tint_gradient.svg` | 宝石 | `currentColor` 用在**渐变的停靠点**上（`stop-color="currentColor"`，另一个停靠点是固定的深色）；上面再压一层 `mix-blend-mode: overlay` 的反光 |

共同要求：

- 根元素写默认颜色：`<svg ... style="color: #b83a3a">`；
- 不用动画；
- 预览图每个交三张：默认色、蓝色 `#3a6fd8`、金色 `#e0b030`。文件名是 `icon_tint_flat.png`、`icon_tint_flat-蓝.png`、`icon_tint_flat-金.png`，另外两个图标同样。截蓝色、金色时只改根元素的 `color`，别的都不动。

### 2.2 `ui_hud_slot.svg`：带"槽"的面板（1280×240）

"槽"是 SVG 里留出来的一个空位，游戏会把自己的文字放进去，比如伤害数字。现有游戏就在用，写法是一个空的组：

```xml
<g id="slot_text"></g>
```

要求：

1. 从 `ui_hud.svg` 复制一份改，题材不变。
2. 面板上加一块**会晃的牌子**，比如挂在两根链子上的铭牌，左右摆 ±4 度，2.4 秒一个来回，循环。CSS 或 SMIL 都行。
3. 槽放在牌子**里面**：在文件里写在牌子的组内，跟着牌子一起晃。
4. 槽的**前面要有东西挡住它一部分**，比如一个锁扣或一段链子压在字框的一角。文件里这个东西写在槽**后面**，这样它就画在上面。
5. 槽是空的，里面什么都不放。
6. 字框大约 220×44，字号 28。字框的中心点坐标（素材坐标，待机第 0 毫秒时）和字号写进动作清单的 `槽`，格式见第 4 节。
7. 预览交两张：
   - `ui_hud_slot.png`：槽是空的；
   - `ui_hud_slot-带字.png`：临时在槽里放一行 `伤害 +128` 截一张，看前后关系对不对。截完把字删掉，交的 SVG 里槽必须是空的。

## 4 动作清单文件 `<id>.json`

以前一次性动作怎么触发只写在 `notes.md` 里，我们的工具读不了。这次给每张**主图**（上次的 10 张，加 `ui_hud_slot`）和**三个染色图标**各交一个同名的 `.json`，把动作列成固定格式。上次的 30 个图标不用交。

格式（例子是巫妖）：

```json
{
  "id": "char_lich",
  "动作": [
    { "名字": "待机", "种类": "循环" },
    { "名字": "施法", "种类": "播一次", "毫秒": 1200,
      "触发": { "class": "act-cast" }, "smil": ["#cast_std_anim"] },
    { "名字": "眩晕", "种类": "进场后循环", "毫秒": 500,
      "触发": { "class": "act-daze" }, "smil": ["#daze_in_anim"] }
  ],
  "混合": "normal",
  "染色": false,
  "槽": {}
}
```

| 字段 | 写什么 |
|---|---|
| `动作` | 每个动作一条。待机不用触发，打开文件就自己播 |
| `名字` | 中文，自己起，直白就行 |
| `种类` | 四选一：<br>· `循环`：一直播；<br>· `播一次`：播完回到待机，我们会把 class 去掉；<br>· `播完停住`：停在最后一帧，不回待机；<br>· `进场后循环`：先播一段，再一直循环，直到我们取消 |
| `毫秒` | `播一次`、`播完停住`：整段多长。`进场后循环`：进场那一段多长。`循环` 不用写 |
| `触发.class` | 要加在根元素上的 class |
| `smil` | 要调 `beginElement()` 的 SMIL 动画 id，**全部列出来**，比如魔像的 32 块碎石就列 32 个 `#debris_smil_0` … `#debris_smil_31`。用 `.end` 自己接上的不用列 |
| `混合` | 根元素上的 `mix-blend-mode`，没写就是 `normal` |
| `染色` | 用了 `currentColor` 的写 `true` |
| `槽` | 没有槽就写 `{}`。`ui_hud_slot` 写成 `{ "slot_text": [中心x, 中心y, 字号] }`，坐标按素材坐标、待机第 0 毫秒 |

一次性动作，CSS 和 SMIL 两种触发方式都要给，单独用哪一种都能把这个动作完整播出来。和上次一样。

## 5 新增的规矩

1. **用 Chrome 157 看**（上次 `notes.md` 写的是 149）。我们的参照是 Chrome 157.0.8103.50，用 Chrome for Testing 的这个版本最好；用 157 的正式版也行。版本写进 `notes.md`。改过的旧文件也请在 157 里重新看一遍，截新的预览图。
2. 不要用这些：`transition`；3D 变换（`rotateX`、`rotateY`、`perspective`、`translate3d` 之类）；`:hover`；`@media`。我扫了上次的文件，都没用，这次也别用。
3. SMIL 的 `begin` 只用三种：时间、`indefinite`、跟着别的动画（`xxx.end`、`xxx.begin + 0.2s`）。**不要用点击、鼠标这类事件。**
4. 根元素上的混合模式，只能用 `normal`、`screen`、`multiply`、`plus-lighter` 这四种。素材里面的元素不受这条限制，16 种随便用。
