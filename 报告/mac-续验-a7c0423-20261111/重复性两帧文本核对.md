# scene_hall 两帧重复性差异：文本与静态坐标核对

## 当前结论

两次运行的对应冻结 SVG 逐字节一致，整份20ms动画值表也逐字节一致；两帧元数据唯一差异是 Chrome 临时 `user-data-dir` 路径。现有文本证据没有发现 XML 路径值、采样时刻、倍率或冻结输入精度不一致。

主代理已确认两张 PNG 存在真实像素差异，并非仅编码不同。首差像素可静态关联到 `#floating_dust_particles` 中两颗尘粒的边缘覆盖区域，但这不能确定栅格、合成或缓存中的哪一环节导致不稳定。**截至本次核对，根因仍未查明；实验1不通过，按需求第9.4节停止后续计算，等待用户在当前聊天作窄选择。**

本文件只作已有文本文件读取、比较和静态XML坐标查询，没有启动 Chrome、比图、重新计算图像指标、哈希大文件或改动源码/原件。下列像素数字由主代理本次 PNG 分析提供，没有在此重算。

### 此关联的边界

两颗圆都在源文件[第2058行](/Users/key_/Desktop/CURRGO/game/svg-render/素材/源文件/复杂测试图/scene_hall.svg:2058)的 `#floating_dust_particles` 内；该组是 `mix-blend-mode: screen`，没有filter祖先。源中也存在固定seed=9的火焰turbulence/位移/模糊，以及大半径雾blur，但这两个首差位置不在火焰滤镜祖先链中。

这些事实只确定了空间关联和输入相同性，**没有证明所有差异都由尘粒导致，也没有证明固定seed滤镜、分层、缓存或某个栅格算法就是根因**。不能据此放宽重复性要求、切换候选冻结策略，或把差异作为可忽略误差报通过。
